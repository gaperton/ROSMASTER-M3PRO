# Introduction to OpenCV
What is OpenCV? Its full name is Open source Computer Vision Library. As shown in the picture

above, we can see the OpenCV logo, which is composed of three small circles of the three primary

colors R, G, and B. In other words, it is an open source API function library for computer vision.

This means that


(1) Whether it is scientific research or commercial application, it can be used for development;


(2) The source code of all API functions is public, and you can see the program steps implemented

internally;


(3) You can modify the OpenCV source code and compile it to generate the specific API functions

you need.


Open the program source code summary - opencv, import the opencv file in it into the

motherboard/virtual machine, and then you can learn opencv.


The image processing on ROSMASTER uses some functions of the OpenCV library, or it can be

said that it is indispensable in most image processing design fields. As early as many years ago,

OpenCV has been very useful in intrusion detection, specific target tracking, target detection, face

detection, face recognition, face tracking and other fields, and these are just the tip of the iceberg

of its applications. Since we know that OpenCV is so versatile, in this chapter of the course we will

introduce you to some very basic image processing functions used in our course, which are also

some common functions. Here we first have a general understanding of these knowledge, and

then there are two practical projects of color recognition and tracking, and face recognition and

tracking to teach you how to get started. However, the powerful application functions provided by

OpenCV are far more than that. If you are very interested in the development of the Opencv

computer vision library and want to learn more, here are a few websites for your reference and

study:


OpenCV official website: [https://www.opencv.org](https://www.opencv.org/)


OpenCV Chinese Forum: [http://www.opencv.org.cn](http://www.opencv.org.cn/)


OpenCV CSDN Forum: [https://bbs.csdn.net/forums/OpenCV](https://bbs.csdn.net/forums/OpenCV)
